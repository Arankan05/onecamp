# Features

This directory contains the feature-specific modules of the OneCamp application. Each feature should follow the same internal structure:

```
feature_name/
├── models/
├── repositories/
├── services/ (or controllers)
├── screens/
└── widgets/
```

## Feature Assignments:
1. auth: Authentication + Profile
2. feed: Social Feed
3. communities: Communities
4. events: Events + Campus Updates
5. chat: Real-time Chat
6. marketplace: Marketplace + Search
7. campus: Campus Updates (shared or specific)
8. search: Search functionality (often shared)
